# App Design v0.6

## 目的

v0.6は、正式157件データ統合後の機能構成を維持したまま、UI/UX改善と `＋記録` のスクロール位置Bug Fixを行う。

新機能追加ではなく、実地利用前の見やすさ、親しみやすさ、iPhone Safariでの自然な操作感を改善する。

## 変更しないこと

- 正式157件の大使館データ
- Day1〜Day10構成
- NEXT中心の操作フロー
- 取得状態管理
- `localStorage` データ構造
- `dataVersion: "1.0"`
- JSON Backup / Restore
- Google Maps導線
- Afghanistanの `地図要確認`
- GitHub Pages運用

## App Name

主タイトル:

```text
大使館スタンプラリー
```

サブタイトル:

```text
世界とつながる 東京散歩
```

UI上で開発Versionは強調表示しない。開発Versionは `docs/work-log.md` で管理する。

## UI Direction

配色は、グリーン、スカイブルー、クリームを基本にする。

意図:

- 屋外利用時に暗すぎない
- 「世界を巡る街歩き」の印象を出す
- Google Maps導線とNEXT情報を埋もれさせない

Day画面では、NEXT大使館名を最重要情報として維持し、Google Mapsボタンを目立たせる。

## v0.6 Design Target

添付された4画面参考画像をDesign Targetとし、次の4画面構成で仕上げる。

1. ホーム
2. Day一覧
3. 今日のルート
4. Day / NEXT

完全なピクセルコピーではなく、明るさ、配色、キャラクター、空・街並み・地球の世界観、カードUI、情報の優先順位を合わせる。

### ホーム

- Sky Blueの空、雲、飛行機、東京の街並みを使う
- 男性、地球、女性を横並びにし、タイトルや吹き出しと重ねない
- 巨大な中央 `STAMP` 表現は使わない
- HeroをiPhone縦画面で大きくしすぎない
- 全体取得状況と主要メニューをHero直下へ置く

### Day一覧

- Day1〜Day10をWhite/Creamのカードで表示する
- Day番号を色分けする
- 現在の取得数と正式件数を表示する

### 今日のルート

- 巡回順、大使館名、住所、取得状態、Google Maps、手動NEXTを一覧表示する
- Day7、Day8の長いルートでも一覧性を優先する
- `＋記録` はこの一覧へsticky/fixed表示しない

### Day / NEXT

- NEXT、大使館名、住所、Google Maps、取得済み、次、その次、`＋記録` の順に優先する
- 女性キャラクターは操作領域と重ならない画面下部の小さな案内役とする
- 長い大使館名は折り返し、横スクロールを発生させない

## Guide Characters

ユーザー提供画像から、左端の男性と右端の女性を案内役キャラクターとして使用する。

- ホーム画面では比較的大きく表示する
- Day画面ではNEXT操作を邪魔しない小さな装飾として表示する
- 操作対象ではないため、装飾画像として扱う
- 人物を元画像の背景ごと矩形に切り抜かない
- 男性、女性をそれぞれ背景透過PNGとして独立させる
- 地球も背景透過PNGとして独立させる
- UIテキスト、大使館名、進捗、ボタンはHTML/CSSで実装する

## Bug Fix

v0.5では、Day画面で `今日のルートを見る` を開いてスクロールすると、`＋記録` ボタンが画面中央付近など不自然な位置に残ることがあった。

原因:

- `＋記録` ボタンに `position: sticky` を使っていた
- 長い `details` 内コンテンツとiPhone Safariのスクロール挙動が重なり、意図しない位置に残って見える場合があった

対応:

- `＋記録` ボタンをDay / NEXT画面の通常の文書フローに戻す
- 長いルート一覧は独立した `今日のルート` 画面に表示する
- スクロール中に中途半端な追従・残留をしないようにする

## v0.6.1 Responsive & Visual Polish

iPhone Safari実機レビューを受け、v0.6の世界観と機能を維持したまま情報密度を調整する。

### Hero

- 高さを従来の約65〜70%へ短縮する
- 男性、地球、女性、雲、飛行機、タイトル、サブタイトルを重ねない
- 下端は抽象的な緑の山形ではなく、東京をイメージした街並みAssetを使う
- 地球とスタンプ風モチーフをブランド表現として残す

### Day一覧

- ヘッダー、カード内余白、カード間隔を縮める
- Day番号の色分けと44px以上の操作領域は維持する
- 一覧を開いた直後にDay1〜Day5以上を確認できる密度にする

### Day / NEXT

- NEXT大使館名は24〜30px、住所は14〜17px、地図ボタンは44〜52pxを目安にする
- `次` と `その次` はNEXTカード内のコンパクトな情報行とする
- `取得済み` は全幅を維持し、`今日のルート` と `＋記録` は2列にする
- 案内役の女性は主要操作の下に小さく置き、専用の大きな縦領域を作らない

### 今日のルート

- ルートカード、余白、文字、操作ボタンを実地利用向けに圧縮する
- Google Maps、手動NEXT、取得状態の操作領域を44px以上にする
- Day7、Day8でも `＋記録` をsticky/fixed表示しない
