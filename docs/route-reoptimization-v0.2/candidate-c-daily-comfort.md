## 残るトレードオフ

- Day4はベナン大使館の文京区側が地理的に孤立し、徒歩のみでは長い。赤羽橋から都心東側を経て後楽園へ抜ける一方向構成だが、公共交通併用候補として残る。

- START / GOALは徒歩時間を基準にv0.1で確認済みの駅から選択した。横浜方面からの乗換・帰宅利便性はPM承認後に時刻表と実利用条件で最終確認する。
- Afghanistanは所在地未確定のため距離・順序計算から除外し、Day10別枠で一度だけ管理する。
