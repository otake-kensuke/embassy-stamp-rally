# Test Plan v0.3

## 目的

最後にDay画面を開いていた場合、Safari再起動後もDay画面から始まることを確認する。v0.2までの保存、NEXT、記録、バックアップ機能が壊れていないことも確認する。

## PC確認

1. `index.html` をブラウザで開ける
2. 初回または `lastScreen` がない状態ではホーム画面から始まる
3. `Day 1を開く` を押すとDay画面が開く
4. 再読み込み後、Day画面から始まる
5. 戻るボタンでホームに戻る
6. 再読み込み後、ホーム画面から始まる
7. `＋記録` 保存後に `記録を保存しました` が表示される
8. 取得済みとNEXT更新がv0.2同様に動く

## iPhone実機確認

1. GitHub Pages URLをSafariで開ける
2. ホームから `Day 1を開く`
3. Safariタブを閉じる、またはSafariを終了して再度開く
4. Day画面から始まる
5. 戻るボタンでホームへ戻る
6. 再度開いたときホーム画面から始まる
7. 取得済み状態、NEXT、街歩き記録が残る

## 回帰確認

- Google Mapsリンクが開く
- JSONバックアップを書き出せる
- JSONから復元できる
- 不正JSONで既存データが壊れない
