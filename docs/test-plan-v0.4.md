# Test Plan v0.4

## 目的

正式Day1 13件の実データで、v0.3までの主要機能が壊れていないことを確認する。

## PC確認

1. `index.html` をローカルHTTP配信で開ける
2. ホーム進捗が `0 / 13` になる
3. `Day 1を開く` を押すとDay画面が開く
4. NEXTが1件目のペルー大使館になる
5. `次` がチェコ大使館、`その次` がクロアチア大使館になる
6. `取得済み` を押すとNEXTがチェコ大使館へ自動更新される
7. 今日のルート一覧に13件が巡回順で表示される
8. ルート一覧から手動NEXTを変更できる
9. Google MapsリンクがHTTPSのGoogle Maps URLになる
10. `＋記録` を保存するとトーストが表示され、振り返りに表示される
11. 再読み込み後も `localStorage` の状態が残る
12. JSONバックアップを書き出せる
13. JSONから復元できる

## iPhone実機確認

1. GitHub Pages URLで13件版が表示される
2. Day1 13件表示
3. NEXT / 次 / その次
4. 取得済み後の自動NEXT
5. 手動NEXT
6. Google MapsがSafariから開く
7. 今日のルート一覧
8. `＋記録` と振り返り
9. Safariを閉じて再度開いても状態が残る
10. JSON Backup / Restore

## PC確認結果

Status: PASS

- ホーム進捗 `0 / 13` を確認
- Day画面でNEXTがペルー大使館、次がチェコ大使館、その次がクロアチア大使館になることを確認
- `取得済み` 後、進捗が `1 / 13` になりNEXTがチェコ大使館へ自動更新されることを確認
- 今日のルート一覧に13件が巡回順で表示されることを確認
- 手動NEXTでフランス大使館へ切り替わることを確認
- Google Mapsリンクが通常のHTTPS URLになることを確認
- `＋記録` 保存後、`記録を保存しました` のトースト表示と約2秒後の自動非表示を確認
- 振り返りに取得履歴と街歩き記録が表示されることを確認
- 同じURLを開き直して `localStorage` の状態が残ることを確認
- JSON Backup / Restore相当の保存JSON構造、`dataVersion` 検証、13件正規化を確認

## 注意

既存のiPhone SafariにPrototype 5件時点の `localStorage` が残っている場合、同じIDの最初の5件は取得状態を引き継ぐ。完全な初期状態で確認したい場合は、SafariのWebサイトデータ削除または別環境で確認する。
