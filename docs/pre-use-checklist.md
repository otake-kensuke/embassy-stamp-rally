# 使用開始前チェックリスト

## 目的

v0.5は実装、PC検証、iPhone実機検証まで完了している。実際のスタンプラリーで使用開始する前に、運用面の確認を行う。

## 事前確認

- GitHub Pagesで最新のv0.5が表示されることを確認する
- iPhone Safariでページを開き直し、Day復元が期待通りであることを確認する
- Day1〜10の選択、NEXT、次、その次が表示されることを確認する
- 各Dayの代表地点でGoogle Mapsが開くことを確認する
- 重点確認5件のGoogle Mapsが開くことを確認する
- Day10 アフガニスタンが `地図要確認` として表示されることを確認する

## バックアップ準備

- 使用開始前にJSON Backupを書き出す
- 書き出したJSONをiPhoneのファイルアプリ等で見つけられることを確認する
- 復元手順を一度確認する
- 夫婦や複数端末で使う場合、端末ごとに保存状態が独立することを理解しておく

## 当日運用

- 取得したら `取得済み` を押す
- 予定と違う順番で回る場合は `今日のルートを見る` から `ここをNEXTにする` を使う
- 写真はiPhone写真アプリで管理する
- Webアプリ内には写真を保存しない
- 迷った場合は公式情報とGoogle Mapsを優先する

## 既知Issue

- Day10 アフガニスタンはPrimary Source上のMap欄が `要確認`
- `prototype/` と `release/` の役割整理は157件統合後の別判断
