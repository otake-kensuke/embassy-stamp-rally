# Release Notes v0.2

## 目的

v0.1で確認できたGitHub Pages + iPhone Safari方式を維持したまま、街歩き記録の保存後に「保存できた」ことが分かるようにする。

## 実装範囲

- `＋記録` 保存後の完了トースト表示
- トーストの自動非表示
- iPhone Safariのキャッシュ対策としてCSS/JS参照にバージョン付きクエリを追加
- 単一HTML版とrelease版の再生成

## 実装内容

`＋記録` で保存を押したあと、bottom sheetを閉じ、画面下部に以下のメッセージを表示する。

```text
記録を保存しました
```

表示は約2秒後に自動で消える。保存処理、`localStorage` のデータ構造、画面構成はv0.1から変更しない。

## iPhone実機確認結果

- GitHub Pages版で `＋記録` を開ける: OK
- 記録を保存できる: OK
- `記録を保存しました` が表示される: OK
- 約2秒後にトーストが消える: OK
- 振り返りに保存した記録が表示される: OK

## 判定

Prototype v0.2の小改善は完了。v0.1の基本方式を維持したまま、保存直後の不安を減らすUX改善が成立した。

## 次の候補

- Safari再起動後に最後に開いていた画面を復元するか検討する。
- Dayデータを5件より少し増やし、件数が増えた時のNEXT表示とルート一覧の使い勝手を確認する。
